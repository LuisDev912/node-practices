# 01-node-basics

This directory practices the basics of Node.js as a runtime inspector showing machine information (such as its total memory, OS, and others).

## Note

On **Windows**, system uptime may be higher than expected due to Fast Startup.
A full restart is required to reset the uptime.

## Usage

``` bash
node index.js
```
or you can also add an argument:
``` bash
node index.js argument
```
